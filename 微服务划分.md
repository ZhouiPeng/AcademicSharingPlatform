# 学术成果分享平台微服务拆分方案

基于详细的接口文档，建议拆分为以下**7个微服务**：

## 1. **用户服务 (User Service)**
**职责**：用户管理、认证授权、门户认领

**接口列表**：
### 1. 注册与登录
- `POST /api/users/normal/register`        # 普通用户注册
- `POST /api/users/login`                  # 多角色登录
- `POST /api/users/logout`                 # 退出登录
### 2. 获取与修改用户信息
- `GET  /api/users/current`                # 获取当前用户信息
- `GET /api/users/{userId}`                # 获取特定用户信息
- `GET /api/users/{authorname}`            # 根据作者名获取作者信息
- `PUT  /api/users/current`                # 修改用户信息
### 3. 密码重置
- `POST /api/users/password/reset`         # 密码重置
- `GET /api/users/password/validation`     # 验证码确认
### 4. 关注与粉丝
- `POST /api/users/follow/{scholarId}`     # 关注学者
- `DELETE /api/users/follow/{scholarId}`   # 取消关注
- `GET /api/users/follows`                 # 查看关注列表
- `GET /api/users/fans`                    # 查看粉丝列表
### 5. 用户升级
- `PUT /api/users/upgrate/{userId}`        # 升级为科研人员(由管理员内部调用)

**数据库**：MySQL

## 2. **学术成果服务 (Achievement Service)**
**职责**：成果CRUD、收藏管理、引用通知

**接口列表**：
### 1. 成果的增删改查下载
- `POST /api/achievements`                              # 上传成果(只要用户ID，作者名通过解析论文得到，添加引用)
- `POST /api/achievements/uncertified`                  # 上传成果(内部调用)
- `PUT  /api/achievements/{achId}`                      # 修改成果
- `DELETE /api/achievements/{achId}`                    # 删除成果
- `GET  /api/achievements/achievements/{achId}`         # 浏览成果详情
- `GET /api/achievements/author/{authorId}`             # 查看当前科研人员的成果列表
- `GET  /api/achievements/{achId}/download`             # 下载成果全文

### 2. 收藏与查看
- `POST /api/achievements/folders`                      # 新建收藏夹
- `POST /api/achievements/{achId}/collect/{folderId}`   # 收藏成果
- `DELETE /api/achievements/{achId}/collect`            # 取消收藏
- `DELETE /api/achievements/collect/{folderId}`         # 删除收藏夹
- `GET  /api/achievements/collections`                  # 查看收藏夹列表

### 3. 检索功能
- `GET /api/achievements/search`                        # 关键词搜索成果
- `GET /api/achievements/filter`                        # 高级筛选成果
- `GET /api/achievements/category/{catId}`              # 分类浏览成果
- `GET /api/achievements/search/sort`                   # 搜索结果排序

**数据库**：MySQL

## 3. **数据同步服务 (Data Sync Service)**
**职责**：外部数据采集、数据清洗、数据库更新

**接口列表**：
- `POST /api/sync/public-db`                      # 从公共数据库拉取数据，上传到学术成果服务成功后，再上传到文件服务内（调用别人）

## 5. **统计分析服务 (Analytics Service)**
**职责**：数据统计、热点分析、报告生成

**接口列表**：
- `GET /api/analysis/hot-topics`                # 分析科研领域热点
- `GET /api/analysis/report/{reportId}`         # 导出热点分析报告
- `GET /api/analysis/achievements`              # 成果数据统计

**数据库**：MySQL

## 6. **系统管理服务 (Admin Management Service)**
**职责**：分类管理、系统配置、操作日志

**接口列表**：

### 1. 修改配置
- `PUT  /api/admin/configs`                 # 修改系统参数配置
- `GET  /api/admin/logs`                    # 查看系统操作日志

### 2. 处理门户认领
- `POST /api/admin/authentications`         # 生成门户认领(随机分配管理员)
- `GET  /api/admin/authentications`         # 获取门户认领
- `PUT /api/admin/authentications`          # 处理门户认领
- `GET /api/admin/getAuthentication`        # 根据用户ID获取门户认领(前端查看门户认领时，调用该接口)

### 3. 处理举报
- `POST /api/admin/report`                  # 生成举报(随机分配管理员)
- `GET  /api/admin/report`                  # 获取举报
- `PUT /api/admin/report`                   # 处理举报
- `GET /api/admin/getReport`                # 根据用户ID获取举报结果(前端查看举报结果时，调用该接口)

**数据库**：MySQL
